# M1 验收说明

## 范围
仅 Web 前端 PoC，React/TypeScript/Vite；不包含后端、真实 AI 分析或持久化。演示数据基于虚构的运营商综调调研场景。

## 验收清单
- [ ] 项目可安装依赖并启动、构建、类型检查通过
- [ ] 三栏工作台与原参考设计主要结构一致
- [ ] 证据分类筛选、全文搜索、来源详情可用
- [ ] 不同原因假设可切换，支持证据与冲突证据可追溯
- [ ] 根据选中假设可创建核验任务，任务可标记完成
- [ ] 客户确认过程只标为演示状态，未核验完成不能模拟确认
- [ ] 需求定义卡 Markdown 导出包含证据及核验结果
- [ ] Playwright 覆盖核心操作且通过
- [ ] 未提交客户真实信息或任何密钥

## 模型与数据关系
Problem 1:N Hypothesis；Hypothesis N:M Evidence（支持/冲突）；Hypothesis 1:N VerificationTask；经确认的 Problem 才能转化为真实 Requirement。

## 后续规划
M2：后端存储、数据导入、资料级来源定位、业务工作流；M3：调用成熟模型完成结构化事实抽取、问题假设建议及证据核验辅助。
